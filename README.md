# 水下考古测线重叠与拼图准入台

直接打开 `index.html` 使用（无构建步骤）。由原来的潜水标记记录扩展为测线重叠与拼图准入工作台。

## 功能

- **测线登记**：每个潜次按测线编号唯一，登记起点/终点坐标（东距 E、北距 N，米）、登记航向、测宽、拍照间隔和潜水员；编号重复将被拒绝。
- **准入判定**：按测线编号顺序取相邻测线——
  - 覆盖率 = 1 − 中心线间距 ÷ 平均测宽，合格区间为 **30%～50%（含边界）**；
  - 相邻航向必须反向交替（相差约 180°，容差 25°）；
  - 任意一项不达标，拼图只进入**待补测**：不能生成成果、不能导出，且**不占用已通过成果版本号**。
- **成果版本**：准入通过后提交才生成只读成果（v1、v2……）；修改坐标、航向、测宽或拍照间隔会改变数据指纹，相关拼图立即失效并按新数据重算，旧成果始终只读归档；仅潜水员变更不影响拼图。
- **重复 / 并发提交**：以数据指纹为键，重复提交或并发连点沿用首次结果，不重复占用版本；待补测提交同样记忆首次结果。
- **一致视图**：测线列表、测线平面图、刷新后的状态都来自同一份 `localStorage` 持久化数据，任何变更统一重绘。
- **地图交互**：平面图上两下点击确定起止坐标，端点可拖拽；测宽带按合格（绿）/不合格（红）着色，相邻对中点标注覆盖率。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `js/survey-rules.js` | 业务判定（纯函数）：几何、覆盖率、航向交替、准入、数据指纹、表单校验 |
| `js/survey-store.js` | 持久化：localStorage 存取、成果版本归档、旧成果只读、重复/并发提交幂等 |
| `js/survey-map.js` | 地图交互：SVG 测线图绘制、点击布点、端点拖拽、选中 |
| `index.html` | 装配层：列表、状态卡、表单、成果版本面板与事件绑定 |

数据存储键：`zfl30SurveyConsole.v1`（localStorage 不可用时自动降级为内存存储）。页面右上角"重置演示数据"可恢复内置示例。
