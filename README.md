# 水下考古测线重叠与拼图准入台

由原「水下考古潜水记录」扩展。直接打开 `index.html` 使用（数据保存在浏览器 `localStorage`，刷新后状态一致）。

## 业务分层

| 文件 | 职责 |
| --- | --- |
| `js/rules.js` | 业务判定：相邻测线覆盖率几何计算、航向交替、拼图准入结论、数据指纹、表单校验。纯函数，不碰 DOM/存储。 |
| `js/store.js` | 持久化：`localStorage` 读写、测线提交去重（重复/并发沿用首次结果）、准入通过成果的只读版本快照。 |
| `js/map.js` | 地图交互：测线/测宽条带/起止点/覆盖率徽标绘制、两次点击取起止点、选中回调。不做判定、不读存储。 |
| `index.html` | 页面外壳 + 三者之间的编排（事件接线、统一渲染）。 |

列表、测线图、准入结论都由同一份 `Store` 数据在每次变更后统一重渲染，刷新后同样从存储恢复。

## 准入规则

- 每个潜次按**测线编号唯一**登记：起止坐标、航向、测宽、拍照间隔、潜水员。
- 相邻测线 = 按测线编号自然排序后的连续两条（L-2 排在 L-10 前）。
- 条带覆盖率 `(平均测宽 − 中心线垂直距离) / 平均测宽`，并要求纵向有搭接投影。
  - 覆盖率 **< 30%（低于三成）** 或 **> 50%（超过五成）** 均不通过；
  - 相邻航向必须**交替**（方向近似相反，默认容差 15°）；
  - 任一相邻对不通过，整个拼图只进入**待补测**：不能生成成果、不能导出、**不占用已通过成果版本号**。
- 修改坐标、航向、测宽或拍照间隔后，数据指纹立即变化：相关拼图即时失效并按新数据重算；
  再次通过后生成 **V2/V3…** 新成果，旧成果（V1…）作为**冻结只读快照**保留，可只读查看、不能再导出。
- 潜水员修改不改变几何，不影响指纹。

## 提交去重

- 重复提交已存在的测线编号，或并发提交同一编号：**沿用首次结果**，后到的数据不会覆盖（Store 按编号合并 in-flight Promise）。
- 成果生成同理：当前数据已有通过成果时，重复/并发生成都沿用首次版本。

## 操作

1. 「登记新测线」→ 在平面图上点两次取起止点（Esc 取消），补全潜水员后提交；也可直接填表。
2. 点击图上测线或列表项编辑；保存后准入结论即时重算。
3. 准入通过后「生成拼图成果」得到只读版本，可用「导出当前成果 JSON」导出该冻结快照。
4. 历史成果在右侧「已通过成果版本」中只读查看。
